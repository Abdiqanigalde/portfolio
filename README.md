# Abdi-gani Musse Omar — Personal Portfolio

A modern, responsive personal portfolio website for a Computer Science and Engineering student at the Islamic University of Technology.

## Features

- Responsive design
- Dark/light theme
- Smooth scrolling
- Animated section reveals
- Project showcase
- Skills and coursework
- Research interests
- Achievements
- Contact section
- GitHub Pages ready
- No backend required

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Local Setup

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Before Publishing

Replace the placeholder values for:

- Email
- GitHub profile
- LinkedIn profile
- GitHub project links
- Profile/project images if desired

## Deployment

This site can be deployed directly with GitHub Pages.

## AI Usage

AI tools may be used during development. Keep a separate `AI-USAGE.md` file containing the actual prompts used during development, as required by the course assignment.
